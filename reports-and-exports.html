Reports and exported tables (page 5)

Page 5 of the app, Report export, gives you the results to keep: two reports and the tables of the data. Everything on this page uses one final normalization method.

Final normalization method

Choose the method first; the buttons stay greyed out until you do. Best is the method with the lowest median RSD% among the QC replicates (here Multivariate (PCA)), and each option shows its median RSD%:

Choose another method when, for example, 3.8 shows that it works clearly better for the compounds you are most interested in.

Reports

Button Report For
QC/QA report (html) the internal report: all quality-control steps, tables and interactive figures, as on pages 2–4 of the app checking and documenting the processing
Summary report (pdf) the external report: the project, the methods and the results in a few pages sharing the results

A progress bar shows how far the report is; the HTML report is shown in the app when it is ready, and Download HTML Report saves it. The reports name the settings that were used, so they document the processing.

Exported tables

Export data into tables writes four Excel files for the final method (and each of their sheets as a .csv file), ready to download:

File Content
….norm.xlsx normalized peak areas of all features (also non-targeted)
….norm_blk.xlsx the same after blank subtraction
….conc.xlsx concentrations of the targeted compounds: QCs, study samples and blanks
….conc_all.xlsx the same with all samples, including the calibration samples

This is the start of a batch sheet of the concentration table of the example (QuaNTA_example_ESIpos.mvis.conc.xlsx), the feature columns first and then the samples:

How to read it

  • Sheets: Full has one row per compound over all batches (average and median of the measured values, the curve used per batch); then one sheet per batch with its limits, statistics, model and Notes, the full text of the note icons of table 4.2.
  • Statistics (minimum, maximum, average, median) use the measured values of the study samples only: values replaced by the LOD/LLOQ rules are left out.
  • Coloured cells in the sample columns are values that were replaced or are above the ULOQ; the last sheet, Legend, explains the colours:
TipReuse the processing

Save the settings with Download settings (.yml) on page 1. Loading the file later, in the app or with run_quanta.R on the command line, processes new data the same way.
