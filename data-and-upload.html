1. Input data and processing

The start page of QuaNTA where metadata is provided, data is uploaded, read and processed using the settings provided by the user. All settings and metadata can be saved as a parameters file for ease of reprocessing with new settings or same settings for new data.

File structure

QuaNTA reads a .txt file formatted according to the MS-DIAL alignment result output format. Upload it as it is, or compressed as .zip or .gz.

The file has two parts: four rows of sample information at the top, and below them one row of headers above all feature (a compound or an unknown peak) rows with its peak area in every sample. This is the top-left corner of the example file:

Batch ID 1 1 1 1

The four sample rows

The four sample rows (shaded above) describe each sample column:

Row Content In QuaNTA
Class the group of the sample, e.g. Healthy, QC1, C0-5 the groups in figures and statistics
File type Sample, QC, Standard or Blank study sample, QC, calibration sample or method blank
Injection order a number the order along the sequence (drift, figures over the sequence)
Batch ID a number blank subtraction and calibration per batch

The feature columns

QuaNTA needs these feature columns (exact names): Alignment ID, Average Rt(min), Average Mz, Metabolite name and Comment. Other columns are ignored.

Naming conventions

The Comment column tells QuaNTA what each feature is:

Comment Meaning
Quant a targeted compound, quantified with a calibration curve
Quant\<class> a targeted compound with a compound class after the backslash, e.g. Quant\ATZ
IS an isotope-labelled internal standard
IS\<class> an internal standard with a compound class, e.g. IS\ATZ
vIS the volumetric internal standard (added to check and correct the volume)
R removed from the data when it is read
empty or anything else a non-targeted feature

The calibration samples (File type = Standard) carry their concentration in the sample name, after Cal, with a dash for the decimal point: Cal0 (the zero calibrant), Cal0-005 (0.005), Cal0-5 (0.5), Cal10 (10). QC samples with the same Class are replicates of one QC material; several QC materials (e.g. QC-low, QC-high) are possible.

Example dataset

The example dataset provided with the QuaNTA app is completely synthetic and has 196 targeted compounds, 22 internal standards, 1 volumetric internal standard and 1000 non-targeted features, measured in 299 samples in 3 batches.

WarningCheck before uploading

When you click Process data, QuaNTA lists Comment values that do not follow the conventions (e.g. quant, IS-ATZ) and column names that look like the required ones but are not exact (e.g. Comment2). Values that look like Quant or IS are shown in red: they would be treated as non-targeted. Fix them in MS-DIAL or in the file and upload again.

Uploading and reading

The initial page has 3 sections: Input and metadata, reading and processing data and logs

Upload file, read and process

  1. If the user has previously saved a parameters file it contains metadata, processing settings and which dataset was uploaded at the time of saving it.
  2. Otherwise, fill in metadata (optional), choose a .txt, .zip or .gz (containing a .txt file) by clicking “Browse” in lower left corner
  3. Choose whether to process batch-wise or globally and read file by clicking “Read data file”.
    Section 2 is now viewable.

Processing settings

The settings are grouped as in the app. Hover the ⓘ next to each in the app for the full explanation; options that the data cannot support (e.g. a volumetric IS option without a vIS) are greyed out.


Processing data

  1. Having chosen your processing settings click Process data. A popup will warn you of any problems detected in the raw data.
  1. Click Proceed to start. The Processing log on the right shows the progress; when it ends with “Finished.”, pages 3 and 4 show the results.
TipSave your settings

Download settings (.yml) saves metadata, processing settings and the name of the dataset.
